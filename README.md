# Concurrent Ticket Reservation System

A C++17-based ticket reservation system designed to explore
concurrency, multithreading, synchronization, and safe resource management.

## Project Goals

- Implement a ticket reservation system.
- Manage concurrent booking requests.
- Prevent race conditions.
- Use mutexes and thread synchronization.
- Apply object-oriented programming principles.
- Write unit tests.

## Technologies

- C++17
- CMake
- Git & GitHub
- Linux (Ubuntu)
